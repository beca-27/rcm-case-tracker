
# RCM Case Tracker

A case tracking application designed for healthcare revenue cycle management teams.

The goal of this project is to help billing departments track appeals, reconsiderations, claim follow-ups, pending documentation requests, and unresolved insurance issues.

## Planned Features

* Create and manage cases
* Add follow-up notes
* Track deadlines and due dates
* Mark cases as resolved
* Search and filter cases
* Overdue case alerts
* Local database storage

## Tech Stack

* C++
* SQLite (planned)
